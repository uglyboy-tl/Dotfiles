# `config/` 与 `desktop/` 按环境划分，而非按内容类型

仓库顶层按**运行环境**分目录：`config/` 装命令行环境的配置，`desktop/` 装桌面环境的，`rpi/` 装树莓派专用的。名字有误导性——`desktop/` 里装的也全是配置——但按环境分让 `./install desktop` 这类组合直接对应到目录，避免同一目录里混装两种环境的东西，从而让"笔记本不装树莓派包、树莓派不装桌面包"成为结构上的默认。

## Considered Options

- **按环境分**（采用）：目录与 `conf.d` 的组合单元一一对应。
- **按应用类型分**（如 `shell/`、`wm/`、`editor/`）：更贴近软件分类，但一个应用可能同时属于多个环境，会逼出"这个文件算哪个环境"的持续争议。
- **全放一个 `config/`**：最简单，但失去按环境组合的能力。

## Consequences

`config` 一词同时是仓库目录名和系统 `~/.config/` 的简称，容易混。缓解办法是永远写全（`config/` vs `~/.config/`），见 [术语表](../CONTEXT.md#易混速查)。
