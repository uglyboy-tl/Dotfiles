# dotfiles 装配模型

本项目的核心词汇：配置如何从仓库装配到系统。写文档、读代码、起名字时以此为准。

配置仓库的术语天然贴着目录，所以"术语"与"路径"在这里是同一件事。定义的**语义与边界**在此，具体文件清单见 [软件与配置路径](reference/software.md)。

## 装配

**源文件**：
仓库里的文件，写在 `conf.d` 声明的右侧。
_Avoid_: 源、来源（"源"字在本项目专指此义）

**目标路径**：
系统里的实际位置，写在 `conf.d` 声明的左侧；通常是符号链接，指向源文件。
_Avoid_: 目标、链接位置

**声明**：
`conf.d/*.conf.yaml` 里"哪个文件链接到哪里"的那一行。只有声明，没有内容。
_Avoid_: 配置（"配置"指内容，见下）

**内容**：
`config/`、`desktop/`、`rpi/` 下的真实配置文件。
_Avoid_: 源（那是"源文件"的位置）

**环境**：
`conf.d` 的组合单元（`default` / `desktop` / `rpi`），不是操作系统。`default` 是命令行基座、始终运行，其余按参数叠加。
_Avoid_: 平台、系统（`platform` 在 crontab 声明里另有其义）

## 渲染

**颜色定义**：
主题的**输入**，`themes/colors/<名>/colors.toml`。
_Avoid_: colors 文件（会与产物混淆）

**模板**：
用 `{{ 变量 }}` 占位的骨架，`themes/templates/<app>.tpl`。

**渲染**：
从模板 + 颜色定义生成应用配置的过程；声明在 `themes/render.conf`。

**产物**：
渲染的输出（`~/.config/<app>/colors.*`、`gtk.css` 等）。产物不手改、不提交。
_Avoid_: colors 文件（会与颜色定义混淆）

**重载**：
让已运行的应用重新读取产物的命令，声明在 `themes/render.conf` 第 4 列。

## 目录

**`conf.d/`**：
装配声明目录。
_Avoid_: 配置目录（它只放声明，配置内容在 `config/`、`desktop/`）

**`config/`**：
**命令行环境**的源文件。
_Avoid_: "系统配置目录"（那是 `~/.config/`）；也不要与 `conf.d/` 混称

**`desktop/`**：
**桌面环境**的源文件。与 `config/` 的划分标准是环境，不是"配置 vs 其他"。
_Avoid_: 桌面配置以外的泛称

**`rpi/`**：
树莓派专用源文件。

**`scripts/`**：
用户脚本（以自研为主，含少量带上游署名的第三方），整个目录链入 `~/.local/bin`。
_Avoid_: 脚本目录（不指名会与 `settings/` 混）

**`settings/`**：
设置菜单系统（入口 + 各设置项 + 函数库）。
_Avoid_: 设置（单说"设置"会与"一个设置项"混淆）

**`themes/`**：
主题**输入**：颜色定义 + 模板 + 渲染声明。
_Avoid_: 主题（"当前主题"是运行状态，不是这个目录）

**`data/`**：
随仓库分发的外部数据（submodule）。
_Avoid_: 资源（含混）

## 状态与覆盖

**状态**：
运行时的当前值，写在 `$XDG_STATE_HOME`（如 `theme/current`、`settings/toggles/<key>`）。会变，不进版本控制。
_Avoid_: 配置

**本地覆盖**：
`~/.config/local/*`、`~/.config/git/local` 等机器私有内容。不存在时静默跳过，不纳入版本控制。

## 易混速查

| 词 | 含义 A | 含义 B | 怎么区分 |
|----|--------|--------|----------|
| config | `config/`（仓库里命令行环境的源文件） | `~/.config/`（系统配置目录） | 说全：`config/` 还是 `~/.config/` |
| conf.d | 装配**声明** | `config/` 是**内容** | 两个平级目录，名字都是"配置"缩写但语义相反 |
| source / 源 | **源文件**（vs 目标路径） | **镜像源**（pip/uv/npm 的下载源，目录 `config/sources/`） | 说"源文件"或"镜像源目录"，别单说 source |
| 主题 | 一套配色定义 | 当前生效的主题 | 说"主题定义"或"当前主题" |
| colors | 颜色定义（输入） | 颜色产物（输出） | 必须点明输入还是产物 |
| settings | 设置菜单系统 | 一个设置项 | 说"设置菜单"或"某个设置项" |
| binup | 第三方二进制管理器 | 它的配置 `binup/config.toml` | 别再写成 UV（UV 是另一个工具） |

## 慎用的说法

| 别用 | 改用 | 原因 |
|------|------|------|
| "UV 配置"指 binup | "binup 配置" | 曾因复制粘贴写错 |
| "源"光说一个字 | "源文件" / "镜像源目录" | 两者都沾"源"，必须说清是哪个 |
| "colors 文件"不说明输入还是产物 | "颜色定义"/"颜色产物" | 二者同名，必须点明 |
| "脚本目录"不指明哪个 | `scripts/` / `desktop/scripts/` / `rpi/scripts/` / `settings/` | 四处都能叫"脚本" |
